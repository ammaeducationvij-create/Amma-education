## 💻 Tech Stack & Architecture

- **Frontend**: Clean Semantic HTML5, Modern CSS3 with CSS Custom Properties (Variables), Responsive Grid & Flexbox, Google Fonts (`Outfit`, `Plus Jakarta Sans`).
- **Logos & Media**: Authentic official DDU-GKY logo (`ddu-gky-logo.png`), Government of Andhra Pradesh Emblem (`govt-logo.png`), and official DDU-GKY rural youth banner graphic (`ddu-gky-banner.jpg`).
- **Interactive Logic**: Vanilla JavaScript (ES6+) with zero external framework dependencies, providing blazing-fast page loads and full offline compatibility.
- **Client Database & Persistence**: Reactive LocalStorage engine (`StorageManager`) pre-seeded with realistic candidate records, full CRUD capabilities, and status tracking.
- **Printable Acknowledgment Engine**: Automatic generation of official student registration slips with unique reference code (`AMMA-2026-XXXXX`), student details, QR placeholder, and `@media print` layout.
- **Application Status Tracker**: Live interactive lookup modal allowing students to search by Mobile Number or Application Reference Number to track admission progress.
- **Administration Dashboard (`admin.html`)**:
  - Secure PIN/Password authentication (`manikanta` / `7396538004` or `admin` / `admin123`).
  - Real-time KPI Metric cards (Total Registrations, Pending, Approved/Enrolled, Hostel Requests, Food Requests).
  - Search & filter toolbar (Text search, Course filter, Status filter, Hostel filter).
  - Data table with direct student action links (Call Student, WhatsApp Student, View Details, Update Status, Print Slip, Delete).
  - Instant **Export to CSV / Excel** feature.
  - Quick "+ Add Walk-In Student" modal for center desk admissions.

## 🚀 How to Run the Website

### Option 1: Direct Browser Launch
Open `index.html` directly in any web browser (Google Chrome, Microsoft Edge, Opera, Firefox, Safari).

### Option 2: Run Local Web Server (Recommended)
Double-click `start-server.bat` or run:
```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```
The server will start at `http://localhost:3000/` and automatically open your default browser.

- **Public Student Portal**: `http://localhost:3000/index.html`
- **Center Administration Portal**: `http://localhost:3000/admin.html`
